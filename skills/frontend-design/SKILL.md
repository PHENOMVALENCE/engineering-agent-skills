# Frontend Design

## Workflow
1. Inspect existing design system, components, routes, state, and data dependencies.
2. Define the page's primary user goal and visual hierarchy.
3. Establish consistent typography, spacing, color, radii, borders, and interaction states.
4. Reuse existing components; extract reusable patterns when repetition is real.
5. Design intentionally for mobile, tablet, and desktop rather than simply shrinking desktop layouts.
6. Preserve forms, validation, localization, routing, and backend behavior.
7. Verify keyboard access, focus states, contrast, labels, semantic HTML, touch targets, loading/error/empty states.
8. Test real content lengths and responsive breakpoints.

## Principles
- Function first, then polish.
- Products/content should dominate commerce interfaces, not decorative hero sections.
- Prefer whitespace and hierarchy over excessive shadows, gradients, and animation.
- Use restrained motion and visible feedback.
- Do not replace dynamic data with static mockups in production code.
